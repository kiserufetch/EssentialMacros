# Essential Macros

Макросы для **Rust** на Windows: пресеты под оружие, бинды на клавиши, при зажатии ЛКМ курсор двигается по заданному паттерну. Настройки (чувствительность, FOV и т.д.) сохраняются в реестре.

## Что нужно

- Windows  
- [.NET Framework 4.7.2](https://dotnet.microsoft.com/download/dotnet-framework/net472)  
- Сборка: открыть `EssentialMacros.csproj` в Visual Studio, восстановить NuGet-пакеты, собрать **Release**. Готовый exe — в `bin\Release\`.

## Важно

Использование макросов в игре может **нарушать правила Facepunch / EAC** и привести к **бану**. Используешь на свой риск.
