# Essential Macros

Настольное приложение для **Windows**, ориентированное на игру **Rust**: пресеты отдачи под разное оружие, бинды клавиш на каждый слот и движение мыши по встроенным паттернам (смещениям), пока зажата **ЛКМ**. Чувствительность, FOV, прицел, поведение при инвентаре и оверлей сохраняются в **реестре Windows**: `HKCU\Software\EssentialM`.

## Возможности

- **Бинды** — назначьте клавишу оружию; по нажатию переключается активный пресет (подсветка в интерфейсе).
- **Скрипты отдачи** — ресурсы `.esse` описывают шаги `MoveR` и `Delay`; при зажатой ЛКМ и выбранном оружии движения применяются через глобальный хук мыши.
- **Настройки** — слайдеры чувствительности и FOV масштабируют смещения; отдельные опции (прицел, фикс инвентаря, оверлей) подстраивают работу под привычный сценарий в игре.

**Слоты оружия в UI:** AK47, Берданка, Beretta, LR300, M249, MP5A4, Pistol, Python, Revolver, SMG, Thompson, M39 (в коде M39 пока использует те же офсеты, что и AK47).

## Что нужно

- Windows  
- [.NET Framework 4.7.2](https://dotnet.microsoft.com/download/dotnet-framework/net472)  
- Visual Studio (или MSBuild) с восстановлением пакетов NuGet  

## Сборка

1. Откройте `EssentialMacros.csproj` в Visual Studio (или соберите из «Командной строки разработчика»).  
2. Выполните восстановление пакетов NuGet.  
3. Конфигурация **Release**.  
4. Результат: `bin\Release\EssentialMacros.exe` (при настройке Costura.Fody зависимости могут быть вшиты в exe).
